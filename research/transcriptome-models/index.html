Explore the training recipes

Single-cell RNA

Presence · Is this gene expressed?

Visible gene IDs→Yes / No

The encoder sees the IDs of expressed genes left in the cell after some have been removed. It learns to distinguish a hidden expressed gene from a measured gene with zero counts.

Identity · Which gene is missing?

ID · ? · ID→Gene ID

Genes are ordered by expression relative to their usual level. The model sees the surrounding IDs and learns the original identity at a selected position.

GPT · Which gene comes next?

IDs so far→Next ID

Expressed genes are ordered from higher to lower expression. At each position, the model uses the preceding sequence, including the current ID, to predict the next gene.

Bin-Class · Which expression category?

Gene ID · ?→Category 1–5

The gene ID stays visible while its expression category is hidden. The target is one of five categories for positive expression.

Bin-Value · What is the bin number?

Gene ID · ?→Bin number 1–50

A cell’s positive expression values are divided into quantile bins. The model predicts the hidden bin as a number, so a prediction two bins away is penalized more than one bin away.

Value · How much was expressed?

Gene ID · ?→Continuous value

The name of each selected gene stays in the input. Its positive expression value is hidden, and the model predicts that value on the log-normalized cell expression scale.

Bulk RNA

Identity · Which gene is missing?

ID · ? · ID→Gene ID

Gene-specific reference distributions determine the order. Selected positive gene IDs are masked and the model reads both sides to recover their identities.

GPT · Which gene comes next?

IDs so far→Next ID

After genes are ranked against gene-specific reference distributions, their IDs form a sequence. The model learns to predict the next ID from the sequence so far.

Bin-Class · Which expression category?

Gene ID · ?→Expression category

Measured genes keep a fixed ID order. The model predicts the original expression category at selected positions. Zero has its own category and positive values use bins 1–64.

Value · How much was expressed?

Gene ID · ?→Continuous value

In fixed gene order, each observed value is encoded with sine and cosine functions. A masked position keeps the gene ID, and its target is the original log-transformed TPM, including measured zeros.

How much did the choice depend on the data split?

In the original comparisons, choosing at 25,000 steps improved the mean rank on all three single-cell datasets. TCGA stayed level and PANACEA slipped slightly. For Tabula Sapiens, the ranks use five-fold mean performance within each tissue and evaluation run.

Adamson and Norman originally used one split each. Repeating selection across five held-out splits changed the result. From initialization to 25,000 steps the mean rank moved from 3.67 to 4.33 on Adamson and from 3.47 to 4.07 on Norman, out of six models.

      Methods

      How to interpret the checkpoint prediction

      LogME uses a frozen model’s representation and the labels or response values for a particular task. The same checkpoint can therefore rank differently on two tasks. At each stage, we averaged three runs for each training recipe and compared its LogME rank with the measured final performance rank using Spearman’s ρ.

      Initialization, 25,000 and 50,000 are training steps. “Final” refers to the checkpoint selected for each training run. The comparisons are retrospective. Across the 36 checkpoint tests on the nine additional datasets, no individual correlation met the 5% threshold after correction for multiple comparisons.

      LogME method · You et al., ICML 2021

      How the scores were calculated

      The model names describe different ways of training an RNA encoder. Within each RNA modality, the models trained on the same corpus. Each score is the mean of three runs. For pretraining gain, we first subtract the matching untrained score in each run, then average the three differences. Both versions use a fitted readout for the task.

      Ranks compare models within one task. The left and right tests can use different units. These rankings describe the models tested here. Small differences in rank can correspond to nearly identical scores.
