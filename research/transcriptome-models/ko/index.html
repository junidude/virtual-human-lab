Transcriptome Models

학습 2만 5천 스텝에서 LogME가 높은 모델일수록 최종 성능도 높은 경향이 기존 데이터셋 5개 모두와 추가 데이터셋 9개 중 8개에서 나타났습니다.

체크포인트 4개 · 기존 데이터셋 5개와 추가 데이터셋 9개

체크포인트 LogME 조기 모델 선택 유전자 발현 검사 연구 결과 방법

초기 LogME로 최종 성능 순위 예측

체크포인트마다 모델을 고정하고, 그 모델이 뽑은 특징이 과제의 학습용 정답을 얼마나 잘 설명하는지 LogME로 점수를 매겼습니다. 체크포인트를 골라 당시의 모델 순위와 최종 평가 순위를 비교해 보세요.

Segerstolpe 세포 유형 분류에서 모델 6종의 LogME와 최종 성능 간 순위 상관은 학습 전 −0.14에서 2만 5천 스텝 후 +0.83으로 바뀌었습니다.

학습 단계별 순위 일치도

체크포인트를 바꿔도 비교 기준인 최종 성능 점수는 같습니다.

순위		모델LogME최종 순위

순위는 반올림 전 점수로 계산했습니다. 표는 소수 셋째 자리까지 표시합니다.

각 점은 데이터셋 하나에서 단일세포 모델 6종 또는 bulk RNA 모델 4종을 비교한 값입니다. 모델마다 세 번 측정한 점수의 평균으로 순위를 매겼습니다. 초기화는 학습 전 상태이며, 최종 체크포인트는 학습 종료 시점의 비교 기준입니다.

이 시점에 LogME 1위 모델과 최종 성능 1위 모델이 일치한 데이터셋은 14개 중 7개였습니다. GDPx2에서는 두 순위가 반대 방향으로 움직였습니다(ρ = −0.80).

초기에 한 모델을 고르면 최종 몇 위일까요?

각 과제의 학습용 데이터에서 LogME가 가장 높은 모델을 고른 뒤, 따로 남겨 둔 평가 데이터에서 그 모델의 최종 순위를 확인했습니다. 평균 순위가 1에 가까울수록 잘 고른 것입니다.

평가 데이터를 다르게 나누면 어떻게 될까요?

기존 비교에서 2만 5천 단계에 모델을 고르면 세 단일세포 데이터셋 모두에서 평균 순위가 좋아졌습니다. TCGA는 같았고 PANACEA는 조금 낮아졌습니다. Tabula Sapiens의 순위는 조직별·평가 실행별로 다섯 폴드의 평균 성능을 사용했습니다.

Adamson과 Norman에서는 처음에 데이터를 한 번씩 나눴습니다. 평가 데이터를 바꿔 가며 다섯 폴드에서 선택을 반복하자 결과도 달라졌습니다. 학습 전과 2만 5천 단계의 선택을 비교하면 여섯 모델 중 Adamson은 평균 3.67위에서 4.33위로, Norman은 3.47위에서 4.07위로 내려갔습니다.

유전자 발현 검사와 생물학적 과제 순위 비교

생물학적 과제와 발현 검사를 고른 뒤 모델 이름을 누르면 두 순위에서 그 모델을 따라갈 수 있습니다.

Tabula Sapiens에서는 유전자 발현 여부를 판별하는 순위와 세포 유형을 분류하는 순위가 여섯 모델 모두 일치했습니다. PANACEA에서는 사전학습 후 네 bulk 모델 모두 약물 반응 예측 점수가 낮아졌습니다.

순위 기준

      연구 결과

      여섯 모델의 순위가 일치한 경우

      Tabula Sapiens에서는 유전자 발현 여부를 판별하는 최종 순위와 세포 유형을 분류하는 최종 순위가 모두 일치했습니다. 사전학습으로 얻은 점수를 기준으로 보면 두 순위가 달라집니다.

      사전학습 후 점수가 낮아진 경우

      PANACEA에서는 네 bulk RNA 모델 모두 사전학습 후 약물 반응 예측 점수가 낮아졌습니다. 각 모델의 학습 전 점수를 기준으로 계산한 결과입니다.

      RNA 질의응답에서는 어떤 모델이 앞섰을까요?

      단일세포 모델 6종이 세포나 샘플의 정체성을 묻는 질문에서 참조 답변에 얼마나 높은 확률을 부여하는지 평가했습니다. 모델마다 한 번의 학습 결과를 사용했습니다.

      방법

      체크포인트 예측을 해석하는 방법

      LogME는 각 모델이 RNA를 표현한 값과 특정 과제의 정답 또는 반응값으로 계산합니다. 그래서 같은 체크포인트도 과제가 달라지면 순위가 달라질 수 있습니다. 각 시점에서 학습 방식별로 세 번의 실행을 평균하고, LogME 순위와 실제 최종 성능 순위가 얼마나 일치하는지 스피어만 순위상관계수(ρ)로 계산했습니다.

      학습 전, 2만 5천, 5만 단계는 사전학습의 진행 시점입니다. ‘최종’은 각 실행에서 선택한 체크포인트를 가리킵니다. 이 결과는 완료된 실험을 되짚어 비교한 것입니다. 추가 데이터셋 9개의 네 시점에서 얻은 상관계수 36개에 다중비교 보정을 적용했을 때 5% 유의수준에서 통계적으로 유의한 개별 상관은 없었습니다.

      LogME 계산법 · You 외, ICML 2021

      점수 계산 방법

      모델 이름은 RNA 인코더의 학습 방식을 나타냅니다. 단일세포 모델끼리, bulk 모델끼리는 같은 데이터로 학습했습니다. 최종 점수는 세 번의 실험을 평균한 값입니다. 사전학습 증감은 매 실험에서 같은 모델의 학습 전 점수를 뺀 후 세 차이를 평균한 값입니다. 학습 전후 모두 과제의 답을 예측하는 판독기를 따로 훈련했습니다.

      순위는 같은 과제 안에서 모델끼리 비교한 결과입니다. 왼쪽과 오른쪽 검사의 점수 단위는 다를 수 있습니다. 여기에 나온 순위는 이번에 평가한 모델에 한정되며 점수가 아주 비슷해도 순위는 갈릴 수 있습니다.
