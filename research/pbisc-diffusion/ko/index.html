같은 생성 세포의 diffusion 과정을 최종 PBMC 예측 라벨의 색으로 따라갑니다. 두 화면에서 실제로 관측한 세포와 비교하고, 두 번째 영상에서는 모델이 생성한 SLE–HC 발현 차이의 변화를 봅니다.

왼쪽 / 실제 노이즈 상태 / PCA

샘플러가 지금 가진 상태.

색이 있는 점 하나는 생성 세포 하나의 현재 diffusion 상태 xₜ이며, value와 support 채널을 갖습니다. 공통 측정 유전자 2,980개에서 실제 관측 세포를 모델 규칙대로 인코딩한 뒤 PCA를 한 번만 학습합니다. 생성 중인 상태는 남아 있는 노이즈를 잘라내지 않고 그대로 투영합니다.

오른쪽 / 예측한 최종 발현 / UMAP

모델이 지금 예상하는 결과.

Denoiser는 매 단계에서 노이즈가 제거된 상태 x̂₀(t)를 예측합니다. Hard gate를 적용한 발현 출력에 실제 관측 세포만으로 학습한 정규화·PCA·UMAP 변환을 적용합니다. 완성된 발현 프로파일에 대한 현재의 예측이 어떻게 달라지는지 보여줍니다.

T cellB cellMonocyteNK cellDCOther
같은 점을 계속 따라가세요.

색은 최종 발현에 고정된 scANVI 분류기를 적용한 예측을 이전 단계에도 유지한 것입니다. T cell, B cell, Monocyte, NK cell, DC, Other로 표시하며, 중간 단계에서 실제로 관측한 정체성을 뜻하지 않습니다. Other는 다섯 그룹 밖의 AIFI 라벨을 모은 범주입니다. 기존 벤치마크처럼 신뢰도 임계값이 0이므로 낮은 신뢰도의 예측도 남아 있습니다. 회색 점은 조건 입력에 사용한 동일 기증자의 실제 관측 세포 4,362개입니다. 이 비교는 독립적인 검증이 아닙니다.

두 번째 영상 / SLE − HC

모델이 생성한
발현 차이를 따라갑니다.

기증자 42명(SLE 30명, HC 12명)에서 각각 1,500개씩 생성한 별도 코호트(총 63,000개 세포)를 사용해 denoising 중 기증자 단위 발현 차이를 봅니다. 각 패널에는 고정된 최종 예측 세포 라벨을 사용합니다. 보라색은 사전에 정한 Hallmark interferon-alpha-response 집합에서 공통 측정 패널에 포함된 61개 유전자이며, 회색은 그 밖의 검정 유전자입니다.

가로축

SLE–HC 효과 크기

두 그룹의 기증자 평균 CPM에 각각 1을 더한 값의 log₂ 비율입니다. 양수는 SLE에서 생성 발현이 더 높다는 뜻입니다.

세로축

각 장면 안의 통계량

BH 보정 q값의 −log₁₀입니다. 매 장면에서 여섯 세포 그룹과 공통 유전자 2,980개를 함께 보정하며, 영상 어디에서든 유의해지는 경우 전체를 보정한 것은 아닙니다.

주요 비교 시점은 최종 단계입니다.

중간 장면은 탐색적으로 봅니다. 세포 그룹과 기증자 포함 기준을 고정하며, 기증자·세포 유형별 최종 세포가 20개 이상이고 각 그룹에 기증자가 5명 이상이어야 합니다. 기준을 충족하지 못한 패널은 그대로 표시합니다. Welch 검정은 기증자별 집계값을 사용하며, 생성기·체크포인트·예측 라벨의 불확실성까지 포함하지는 않습니다.

두 좌표계는 조건 입력과 동일한 기증자의 실제 관측 세포만으로 학습합니다. 실제 상태 PCA를 위해 관측 카운트를 체크포인트의 value scaler와 support 규칙으로 인코딩합니다. 발현 UMAP에는 공통 유전자 패널의 합을 10,000으로 정규화하고 log1p·참조 스케일링·PCA를 적용합니다. 생성 세포에는 마지막 장면까지 동일한 변환과 고정 좌표축을 사용합니다. 두 화면은 서로 다른 좌표계입니다.

초기 예측이 관측 참조 분포 밖에 있더라도 UMAP은 참조 이웃 근처에 배치합니다. 군집이나 궤적처럼 보이는 모양은 투영의 영향일 수 있습니다. 영상의 시간은 계산 과정이며 세포 분화나 생물학적 시간이 아닙니다. 최종 라벨은 주석 부여를 위한 한 번의 seeded Poisson readout으로 예측합니다. 투영과 발현 분석에서는 연속적인 생성 발현값을 유지합니다.
