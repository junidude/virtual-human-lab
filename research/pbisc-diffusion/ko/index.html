모델 관찰 / PBISC–Diffusion

노이즈에서
생성 세포까지.

같은 생성 세포들이 diffusion 샘플링을 거치는 과정을 따라갑니다. 두 화면을 함께 보면서 실제 노이즈 상태와 모델이 예측하는 최종 발현 패턴이 어떻게 달라지는지 확인할 수 있습니다.

샘플러의 내부를 보다

하나의 고정된 PBMC pseudobulk 조건.
시작부터 끝까지 동일한 세포들.

실제로 기록한 모델 상태
고정된 투영 · 유지되는 세포 ID

영상 읽는 법

하나의 생성 과정을 보는 두 가지 관점.

왼쪽 / 실제 노이즈 상태 / PCA

샘플러가 지금 가진 상태.

점 하나는 생성 중인 세포 하나의 현재 diffusion 상태 xₜ입니다. 각 상태는 모델이 다루는 유전자마다 value와 support 채널을 갖습니다. 고정된 선형 PCA 투영을 통해 노이즈가 제거되면서 이 상태가 어떻게 바뀌는지 따라갑니다.

오른쪽 / 예측한 최종 발현 / UMAP

모델이 지금 예상하는 결과.

Denoiser는 매 단계에서 노이즈가 제거된 상태 x̂₀(t)를 예측합니다. 이 예측에서 얻은 발현 출력을 고정된 UMAP 참조 좌표계에 표시합니다. 샘플링이 진행될수록 완성된 발현 프로파일에 대한 현재의 예측이 어떻게 달라지는지 보여줍니다.

같은 점을 계속 따라가세요.

색은 최종 생성 발현 프로파일에서 나눈 그룹을 나타내며, 영상 내내 같은 세포 ID에 유지됩니다. 이 그룹은 생물학적 세포 유형 주석이 아닙니다. 영상이 진행되는 시간은 계산 단계이며, 세포 분화나 생물학적 시간을 뜻하지 않습니다.

좌표계의 참조는 별도로 생성한 세포의 최종 프로파일로 구성했습니다. PCA와 UMAP을 한 번만 학습하고, 추적 세포는 마지막 장면까지 모든 기록 시점에서 동일한 변환을 거칩니다. 각 화면의 좌표축 범위도 고정합니다. 두 화면은 서로 다른 좌표계이므로 두 화면의 거리를 직접 비교할 수는 없습니다.

초기 상태는 최종 참조 분포에서 멀리 떨어져 있을 수 있습니다. UMAP은 이런 상태도 참조 데이터의 이웃 근처에 배치하므로 초기 군집이나 궤적처럼 보이는 모양은 투영의 영향일 수 있습니다. 실제 상태를 표시한 PCA를 함께 보되, 두 화면만으로 생성 품질을 평가할 수는 없습니다.
