How to read the film

Two views of the same generation process.

Left / actual noisy state / PCA

What the sampler holds.

Each point is one generated cell’s current diffusion state, xₜ. This state contains a value channel and a support channel for every modeled gene. A fixed linear PCA projection lets us follow that state as noise is removed.

Right / predicted clean expression / UMAP

What the model expects.

At each step, the denoiser predicts a clean state, x̂₀(t). Its expression output is placed in a fixed UMAP reference. This panel shows how the current estimate of the completed profile changes as sampling proceeds.

Keep your eye on the same points.

Colors identify groups in the final generated expression profiles and stay attached to the same cell IDs throughout the film. These groups are not biological cell-type annotations. The horizontal progression represents computation, not cell differentiation or biological time.

Recorded states, without motion interpolation

The projection reference is built from separately generated final profiles. PCA and UMAP are fit once, and the tracked cells pass through the same transforms at every recorded step, including the final frame. Each panel keeps its own fixed axis limits. The two panels are different coordinate systems; their distances cannot be compared directly.

Early states can lie far from the final reference distribution. UMAP still places them near reference neighbors, so early clusters or apparent trajectories can be projection effects. The actual-state PCA provides a complementary view, but neither panel measures generation quality on its own.
